# Segurança

O runtime é uma ferramenta científica local, sem servidor nem envio de telemetria. Use apenas os novos arquivos sintéticos gerados. Não envie medições de terceiros, credenciais ou documentos privados em Issues, PRs, artefatos ou exemplos.

## Reportar privadamente

Verifique se o repositório oferece **Security → Report a vulnerability**. A disponibilidade desse recurso depende do proprietário e não foi confirmada administrativamente. Se indisponível, use o canal de contato já publicado no site oficial da JV Engineering para solicitar um canal privado; não envie o conteúdo sensível em mensagem inicial ou Issue pública. Não foi criado endereço de segurança fictício, SLA ou programa de recompensas.

Informe versão/commit, plataforma, pré-condições, impacto e reprodução mínima com dados sintéticos. Não publique credenciais ou exemplos de exploração contra sistemas de terceiros. Não teste credenciais encontradas.

Somente a implementação sintética atual é mantida; o script em `legacy/` não é suportado ou recomendado. Nenhuma afirmação de ausência universal de vulnerabilidades é feita. Consulte [ameaças e limites](docs/security.md).
